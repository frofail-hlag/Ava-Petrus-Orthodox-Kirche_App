# St. Petrus Koptisch-Orthodoxe Kirche Hamburg — App V1.2

Design + Information Architecture prototype for the bilingual church app.

## V1.2 focus
- Main navigation: **Home | Kirche | Spiritual | Medien | Community**
- Profile/settings moved to the top-right so the five primary tabs stay focused.
- Church website information is mapped into natural app destinations instead of copied as website navigation.
- Added dedicated areas for: About the Coptic Church, St. Mark, St. Petrus, Pope Tawadros II, priests, contact, media library.
- Sunday School remains a **separate app concept**, with the three class cards retained in the main app as an entry point.
- German + Arabic UI architecture is included.
- Current content is intentionally a prototype; production content should be approved by the church and maintained through a CMS.

## Run locally
Open `index.html` in a browser, or serve the folder with any static web server.

## GitHub Pages
Upload the contents of this folder to a repository and enable GitHub Pages from the repository's Pages settings using the main branch/root.

## Important
This is not yet a production backend. Dates, liturgy schedules, media, contact workflows, accounts, notifications and community data are placeholders for the product/build phase.
